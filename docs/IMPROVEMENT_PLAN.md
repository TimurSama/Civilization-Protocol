# ДЕТАЛЬНЫЙ ПЛАН ДОРАБОТКИ VODeco PLATFORM

**Дата создания:** 2024-12-27  
**Версия:** 1.0  
**Основа:** Результаты аудита от 7 ролей

---

## 🎯 ПРИНЦИПЫ ДОРАБОТКИ

### Основные принципы:
1. **Интерактивность вместо текста** - все данные в виде дашбордов, графиков, метрик
2. **Попапы вместо длинных описаний** - детальная информация в попапах с кнопками переходов
3. **Реальные данные** - интеграция всемирных данных о экологии и работе платформы
4. **Рабочие компоненты** - все элементы функциональны, не просто визуализация
5. **Без продающих форм** - никаких стандартных landing-форм, только интерактивные элементы

```typescript
interface MetricCard {

  icon?: ReactNode;
  trend?: 'up' | 'down' | 'stable';
  trendValue?: string;
  onClick?: () => void; // Открывает попап
  popupContent?: ReactNode;
  linkTo?: string; // Переход на страницу
}
```

#### InteractiveChart (Интерактивный график)
```typescript
interface InteractiveChart {
  data: ChartData;
  type: 'line' | 'bar' | 'pie' | 'area';
  interactive?: boolean;
  onPointClick?: (point: ChartPoint) => void; // Открывает попап
  popupContent?: (point: ChartPoint) => ReactNode;
}
```

```typescript
interface InfoPopup {

  size?: 'sm' | 'md' | 'lg' | 'xl';
  actions?: Array<{
    label: string;

    variant?: 'primary' | 'secondary';
    linkTo?: string;
  }>;
}
```
